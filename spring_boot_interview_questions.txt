1.  What is Spring Boot?
Ans: 1. Spring Boot is a Java framework, that makes easy to create java application.
     2. It simplifies the configuration, using auto-configuration.( no need to do XML configuration)
	 3. It solve dependency management, no need to handle dependencies manually.
	    Suppose we want web dependency  we can add <spring-boot-starter-web>
		it will download and add all web related dependencies in our project and also do auto-configure.
     4.	It provides Embedded Server(Tomcat)	
	 5. It provides capability of Rapid Application Developement(RAD),
	    using spring initializer we can simply create project and can add all required dependencies.
	 
2. Why spring boot over spring?
Ans: 1. Easy to use- remove boilerplate codes
     2. Rapid Developement- auto-configure enables developer to quickly develop apps.
	 3. Embedded Server: tomcat
	 
3. Working of spring boot?
Ans: 1. When we build(maven build/reload) our project then dependencies will be download.
Ans: 2. When we run our Spring Boot project then it starts scanning the starter dependencies in pom.xml and
        do auto-configuration for all dependencies.
        
4. How spring boot starts?
Ans: 1. Starts by calling main() method of main class.
     2. After that run() method of SpringApplication called, and this run method startes the application on embedded
        web server by creating an application context and initializing it.
	    
	
		Application context is a Container of Beans.
		
		//Key Points about ApplicationContext:
        Container of Beans: ApplicationContext reads the configuration (either XML or annotations) to create the beans 
		                    and inject their dependencies.

        Dependency Injection: The ApplicationContext manages the dependencies of beans using either constructor or 
		                      setter injection.

1.How to schedule task in spring boot?
Ans:  1. Schdeuling is a process to schedule a task to excecute at specific time.



package com.example.scheduledtasks;

import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;

@Component
public class FileCleanupTask {

    // Simulate a cleanup task that runs every 5 seconds after the previous task finishes
	
    @Scheduled(fixedDelay = 5000)
    public void cleanUpTemporaryFiles() {
        try {
            // Simulating some work, like cleaning up temporary files
            System.out.println("Cleanup started at: " + System.currentTimeMillis());

            // Simulating a long-running task (e.g., file deletion or database cleanup)
            Thread.sleep(3000);  // Simulate task running for 3 seconds

            System.out.println("Cleanup finished at: " + System.currentTimeMillis());
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
    }
}

@Scheduled(fixedDelay = 5000): This annotation ensures that the cleanUpTemporaryFiles method will 
run every 5 seconds after the completion of the previous execution. The delay starts after the task 
has completed.

Thread.sleep(3000): Here, we're simulating a cleanup task that takes 3 seconds to complete 
(representing the time it takes to clean up files, for example).

System.currentTimeMillis(): This is used to log the time when the task starts and finishes so
 we can see the fixed delay in action.

import org.springframework.cache.annotation.Cacheable;
import org.springframework.stereotype.Service;

@Service
public class UserService {

    // Cache the result of this method with the key 'user_{id}'
    @Cacheable(value = "users", key = "#id")
    public String getUserById(int id) {
        simulateSlowService(); // Simulate a slow method
        return "User" + id;
    }

    // Simulating a slow service (e.g., database call)
    private void simulateSlowService() {
        try {
            Thread.sleep(3000); // 3 seconds delay
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
    }
}
================================================@CacheEvict
1. Evict removes a cached entry from a cache
2.value: Specifies the name of the cache where the entry is stored.
3. key: The key that is used to store the cache entry



import org.springframework.cache.annotation.CacheEvict;
import org.springframework.stereotype.Service;

@Service
public class UserService {

    // Evict the cache entry with the key 'user_{id}' after a user is deleted
    @CacheEvict(value = "users", key = "#id")
    public void deleteUser(int id) {
        // Code to delete the user from the database
        System.out.println("User with id " + id + " deleted.");
    }

    // Evict all entries in the 'users' cache (e.g., when clearing all users)
    @CacheEvict(value = "users", allEntries = true)
    public void clearUserCache() {
        System.out.println("All user cache entries have been evicted.");
    }
}

===============================================@CachePut
1.Update the cache: Used when you want to update the cache with the result of a method execution.

import org.springframework.cache.annotation.CachePut;
import org.springframework.stereotype.Service;

@Service
public class UserService {

    // Update the cache with the latest user data
    @CachePut(value = "users", key = "#user.id")
    public User updateUser(User user) {
        // Code to update the user in the database
        System.out.println("Updating user: " + user);
        return user; // The updated user is returned and cached
    }
}
